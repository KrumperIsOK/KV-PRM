# Dataset artifact

`math.parquet` is a snapshot of
[`qwedsacf/competition_math`](https://huggingface.co/datasets/qwedsacf/competition_math)
used by the example pipeline. Dataset loading and splitting behavior is defined
in `src/dataset_handler.py`.

Other paper datasets are loaded from Hugging Face at runtime:

- [`openai/gsm8k`](https://huggingface.co/datasets/openai/gsm8k)
- [`HuggingFaceH4/aime_2024`](https://huggingface.co/datasets/HuggingFaceH4/aime_2024)
- [`yentinglin/aime_2025`](https://huggingface.co/datasets/yentinglin/aime_2025)

Their original licenses and terms apply.
